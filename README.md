# resume-source

Selena Zhi's PM resume source for AI job-matching tools. This repo is the live package: it keeps getting updated as Selena applies. The original resume template (her master resume page) is a separate archive and is never changed from here.

- [`resume_source.md`](resume_source.md): full resume bullets, the 7 resume directions, default bullet set per direction, and matching rules.
- Plain-text link for AI tools: https://raw.githubusercontent.com/SelenaChi/resume-source/main/resume_source.md
- [`CHANGELOG.md`](CHANGELOG.md): what changed in each version.
- [`versions/`](versions/): frozen snapshot of every version. Old versions are never deleted or overwritten.
- [`learning/`](learning/): final bullets from each application, used to improve the source over time.
