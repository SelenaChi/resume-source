## How to use this page for each job posting
1. Pick ONE direction (plus an optional backup): AI PM / Growth PM / B2B SaaS PM / E-commerce & Consumer PM / APM / Data-heavy PM / Ads PM.
   - LLM, agents, AI features → AI PM
   - activation, retention, monetization, funnel, experimentation → Growth PM
   - enterprise customers, internal platforms, workflow, admin/seats → B2B SaaS PM
   - e-commerce, retail, DTC, checkout, consumer marketplace → E-commerce & Consumer PM
   - title says APM / Associate / New Grad / Rotational, or 0-2 yrs required → APM
   - metrics, SQL, analytics, data platform, pipelines → Data-heavy PM
   - ads, ranking, creative, advertisers, ad tech → Ads PM
2. Fit: High / Medium / Low. Background: ~1 yr full-time PM + 3 PM internships, Berkeley MEng HCI. Mark Low if 5+ yrs or a CS degree / domain license is required.
3. Start from that direction's default bullet set (table below), then list the 3-5 bullet IDs most relevant to the JD (to lead each section).
4. Suggest at most 2 edits: one bullet to cut, and/or one JD keyword to work into an existing bullet. Never invent new numbers.
5. Output one row per job: Company | Role | Link | Direction (backup) | Fit | Key bullets | Edits
