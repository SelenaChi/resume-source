# Learning log

Each time Selena edits bullets for a job, or sends the final resume Muse produced, the final wording is saved here as one file per application: `YYYY-MM-DD_company_role.md`. Files are only added, never edited or deleted.

Each file records: the job, the direction used, the final bullet text as sent, and how it differs from resume_source.md at that time.

When the same kind of edit shows up again (for example, she keeps rewording T4 the same way for Ads roles), that preferred wording is folded into resume_source.md as a new version, with a CHANGELOG entry that names the log files it came from.
